# Core Architecture
- **Next.js (v16.2.0):** Leveraging the App Router for a modular and performance-first architecture.
- **React (v19.2.4):** Utilizing the latest React features for building responsive UI components.
- **TypeScript (v5):** Ensuring robust type safety and improved developer experience.

# Styling & Components
- **Tailwind CSS (v4):** Providing a fast and utility-first approach to styling.
- **shadcn/ui:** Component system built on top of Radix UI to ensure consistency, high visual fidelity, and accessibility.
- **Lucide React:** Providing a comprehensive and consistent icon set across the platform.

# Key Integrations
- **Google Maps API (@react-google-maps/api):** Providing the core mapping engine for property discovery.
