# Specification: Property Management Dashboard

## Overview
This track implements a robust Property Management Dashboard for agents to track and manage their property portfolio.

## Requirements
- Stats Overview (Total Listings, Active, Pending Sale).
- Property List Table (Property Details, Price, Status, Actions).
- Search/Filter and "Add New Property" interaction.
- Professional dark/light mode dashboard interface aligned with `prd/property_management_dashboard/`.

## Components
- `StatCard`: Individual summary widget.
- `PropertyTable`: Main container for property rows.
- `PropertyRow`: Table row for listing management.
- `DashboardHeader`: Header section with Add/Filter buttons.
