# Specification: Admin User Directory Cards

## Overview
This track implements the admin user directory card system, allowing administrators to manage and view a list of users with their statuses.

## Requirements
- Display a list of users in a card format.
- Include user status (Active, Pending, etc.) using a status badge.
- Alignment with `prd/admin_user_directory_cards/screen.png`.

## Components
- `UserCard`: Individual card component.
- `UserDirectory`: Main list view container.
- `UserStatusBadge`: Badge for status visualization.
