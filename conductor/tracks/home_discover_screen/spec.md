# Specification: Home Discover Screen

## Overview
This track focuses on building the primary discovery experience for LuxeEstate. This screen serves as the landing page for users, featuring a hero search experience, trending properties, and personalized recommendations.

## Requirements
- **Hero Section:** High-impact search bar integrated with the background or a compelling hero image.
- **Trending Properties:** Horizontal scrolling or grid view of top-rated properties.
- **Categorization:** Quick access to property types (e.g., "Houses", "Apartments").
- **Design:** Align with `prd/home_discover_screen/screen.png`.
- **Interactivity:** Property cards must be interactive, showing core info (price, location, beds/baths).

## Components to build
- `PropertyCard`: Reusable component for property previews.
- `HomeHeader`: Specialized search-focused header.
- `CategoryBar`: Horizontal navigation for property types.
- `PropertySection`: Grid display for categorized properties.
