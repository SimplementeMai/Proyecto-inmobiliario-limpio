# Specification: Add/Edit Property Form

## Overview
This track implements the form for adding new properties or editing existing ones, as defined in `prd/add_edit_property_form/`.

## Requirements
- Form with fields for Title, Price, Description, Location, and Property Details (Beds/Baths).
- Image upload/management.
- Validation for all fields.
- Align with `prd/add_edit_property_form/screen.png`.

## Components
- `PropertyForm`: Main form component.
- `ImageUploader`: Component for property images.
- `FormFields`: Reusable input/select fields.
