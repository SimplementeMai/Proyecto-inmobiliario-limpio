# Specification: Core UI Infrastructure & Navigation

## Overview
This track focuses on establishing the core visual and structural foundation of the property platform. It includes setting up the primary layout, navigation systems, and branding as defined in the Product Guidelines.

## Requirements
- **Global Layout:** A consistent shell containing the Header and Footer.
- **Header Navigation:** Responsive menu with links for "Buy", "Rent", "Sell", and "Saved Homes".
- **User Actions:** Search icon, notification bell, and user avatar as seen in the PRD.
- **Branding:** Apply the nature-inspired green (`#006611`) to primary elements.
- **Component System:** Leverage shadcn/ui for NavigationMenu, Button, and Avatar components.
