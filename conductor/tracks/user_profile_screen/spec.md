# Specification: User Profile Screen

## Overview
This track implements the user profile management screen, allowing users to view and edit their personal information, security settings, and saved property preferences.

## Requirements
- View and edit user details (Name, Email, Profile Picture).
- Security section (Password change/Two-Factor settings).
- Alignment with `prd/user_profile_screen/screen.png`.

## Components
- `UserProfileForm`: Main form for user data.
- `SecuritySettings`: Form section for password/auth updates.
- `ProfileAvatar`: Component for profile picture management.
