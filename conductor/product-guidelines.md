# Design Principles
- **Modern & Clean:** Prioritizing a clean aesthetic with high visual fidelity, structured grids, and subtle shadows. Leveraging the **shadcn/ui** component library for consistent and polished interface elements.
- **Visual First:** Property imagery must be the hero of every page. Layouts should be designed to showcase high-resolution visuals that help tell the property's story.
- **Performance Oriented:** Interaction design should be optimized for speed and seamless transitions to ensure a responsive discovery experience.
- **Accessible & Inclusive:** Commitment to high standards of accessibility, ensuring intuitive navigation for all users via keyboard and screen readers.

# Branding
- **Color Palette:**
    - **Primary:** Nature-inspired Green (`#006611`) to convey a sense of trust, growth, and professionalism.
    - **Backgrounds:** Clean neutrals for light/dark modes that allow primary colors and property imagery to stand out.
- **Typography:** Using high-quality sans-serif fonts for clarity and modern feel.

# UX & UI Guidelines
- **shadcn/ui First:** Prioritize using existing shadcn/ui components (Buttons, Inputs, Dialogs, etc.) and their variants to ensure design system consistency.
- **Visual Fidelity:** Strictly follow the layouts, spacing, and icon usage from the project's PRD screens (`prd/**/screen.png`).
- **Interaction Feedback:** Use clear states for hover, focus, and active elements to provide intuitive user feedback.
